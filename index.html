How It Works

  1. Research

    RegulArk reads the reference drug's approved labeling and the current requirements.

  2. Draft

    It drafts each section of your dossier.

  3. Review

    Every change is shown side by side with the reference and explained.

  4. Approve and record

    A named person on your team approves each change, and every decision is kept on record.

Where We Start

US generics (ANDA), Module 1 labeling: the draft labeling, the side-by-side comparison with the reference label, and the annotated draft.

Module 1, where we start. Regional administrative information, including the labeling.

Module 2. Summaries of the information in Modules 3 to 5, written to a fixed structure.

Module 3. Quality: the drug substance, the finished product, and how they are made and tested.

Module 4. Nonclinical study reports, where a dossier needs them.

Module 5. Clinical study reports. For a generic, mainly the bioequivalence studies showing it matches the reference drug.

Next: the rest of the dossier (Modules 2 to 5), then dossiers for other markets.
